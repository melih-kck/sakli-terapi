# Security Policy

## Supported Version

Only the latest commit on `main` is maintained. The public deployment runs in
safe portfolio-demo mode and does not accept real users, payments, or clinical
records.

## Reporting a Vulnerability

Please do not disclose security vulnerabilities in a public issue.

Use GitHub's [private vulnerability reporting](https://github.com/melih-kck/sakli-terapi/security/advisories/new)
and include:

- the affected route or component;
- clear reproduction steps;
- the observed and expected behavior;
- potential impact;
- relevant browser, device, or request details.

Do not include real health, identity, authentication, or payment data in a
report. Reports will be reviewed before any public disclosure.
